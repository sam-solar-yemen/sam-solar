# سام سولار — Sam Solar

نسخة React/Vite عربية متوافقة مع Supabase، مبنية على تفاصيل المشروع المرسلة في المحادثة.

## التشغيل
1. انسخ `.env.example` إلى `.env`.
2. ضع `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` من مشروع Supabase.
3. نفّذ `supabase/schema.sql` في SQL Editor في Supabase.
4. `npm install`
5. `npm run build`
6. `npm run dev`

## ملاحظة مهمة عن قاعدة البيانات
ملف التفاصيل لا يحتوي على تصدير Schema فعلي من قاعدة بيانات المستخدم؛ لذلك أُرفق Schema متوافقًا مع الجداول والحقول التي ظهرت في المشروع. لا ينبغي الادعاء أن التطابق مع قاعدة خارجية غير مرفقة تم التحقق منه حرفيًا. إذا كانت قاعدة Supabase الحالية مختلفة، يجب مطابقة أسماء الأعمدة قبل التشغيل الإنتاجي.

## الإدارة
الدخول الإداري هنا يعتمد على Supabase Auth + جدول `users` ودور المستخدم، وليس كلمة مرور ثابتة داخل الواجهة.
